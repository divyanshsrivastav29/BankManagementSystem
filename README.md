# Bank Management System

A web-based Bank Management System developed using Python, Flask, MySQL, HTML, CSS, and JavaScript.

## Features

- Secure admin login and logout
- Dashboard with customer, account, and transaction statistics
- Customer management
- Bank account creation and management
- Deposit and withdrawal operations
- Fund transfers
- Transaction history
- Reports and statements
- Form validation and access protection

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** MySQL
- **Version Control:** Git and GitHub

## Installation and Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/divyanshsrivastav29/BankManagementSystem.git
   cd BankManagementSystem
   ```

2. Create and activate a virtual environment:

   ```powershell
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   ```

3. Install dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Configure your MySQL database and environment variables in a local `.env` file. Never upload your secrets to GitHub.

5. Run the application:

   ```bash
   python app.py
   ```

6. Open the local URL shown in the terminal, usually `http://127.0.0.1:5000`.

## Security Note

This project is intended for educational and demonstration purposes. Do not use it to manage real customer funds or sensitive financial information.
